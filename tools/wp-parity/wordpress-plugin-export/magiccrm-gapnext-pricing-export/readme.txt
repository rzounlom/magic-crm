Admin-only export of Generations Event Planner 3.3.0 effective pricing for MagicCRM.

== Description ==

Downloads JSON of effective catalog prices (including administrator overrides) and active custom packages. Does not modify the Event Planner plugin or store customer data.

== Installation ==

1. Upload the ZIP via Plugins → Add New → Upload Plugin.
2. Activate.
3. Ensure Generations Event Planner — Next 3.3.0 is active.
4. Open Event Planner → Export pricing and download the JSON.
